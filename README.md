##  DESCRIPTION

**jesikaajz.github.io** is my personal corner on the web — a fully responsive portfolio site built with HTML, CSS, and JavaScript. It provides an overview of my journey, technical interests, and key projects. The site includes contact information, certificates (such as the C++ certification), an image gallery, and interactive elements to engage visitors.[reference:0][reference:1]

- Site structure and navigation design

### 2. Design
- Responsive layout for desktop and mobile devices

### 3. Implementation
